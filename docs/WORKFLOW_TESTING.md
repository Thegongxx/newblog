## 🔧 问题排查

### 常见问题

#### 文章不显示
1. 检查frontmatter格式是否正确
2. 确认`published: true`设置
3. 验证文件路径是否正确
4. 检查Markdown语法错误

#### 笔记不显示
1. 检查文件扩展名是否为`.md`
2. 验证frontmatter格式
3. 确认文件编码为UTF-8
4. 检查文件权限

#### 部署失败
1. 查看Vercel部署日志
2. 检查构建错误信息
3. 验证依赖项是否正确
4. 确认环境变量配置

#### 数据库同步问题
1. 检查Supabase连接
2. 验证表结构
3. 确认RLS策略
4. 检查API调用
