# Hello World - 博客系统测试

欢迎来到我的博客！这是第一篇测试文章，用来验证整个内容管理和发布流程。

## 工作流程测试

这篇文章将测试以下工作流程：

1. **Obsidian编写** - 在Obsidian中创建Markdown文件
2. **Git同步** - 提交到GitHub仓库
3. **自动部署** - Vercel自动部署更新
4. **数据库同步** - 内容同步到Supabase数据库

## 技术栈

这个博客使用了以下技术：

- **前端**: React + TypeScript + Vite
- **样式**: Tailwind CSS
- **动画**: Framer Motion
- **数据库**: Supabase
- **部署**: Vercel
- **内容管理**: Obsidian + Git

## 结语

如果你能看到这篇文章，说明整个工作流程运行正常！
