## 技术栈

这个博客使用了以下技术：

- **前端**: React + TypeScript + Vite
- **样式**: Tailwind CSS
- **动画**: Framer Motion
- **数据库**: Supabase
- **部署**: Vercel
- **内容管理**: Obsidian + Git
